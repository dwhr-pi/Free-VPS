# Free VPS – deutsche Übersicht

Die aktuelle Dokumentation beginnt in [README-de.md](README-de.md).

**Projektpflege: 21.11.2026.** FreeVPS dokumentiert legitime Entwicklungsumgebungen und die Verwaltung eigener VPS. GitHub Actions wird ausschließlich für projektbezogene CI/CD genutzt, Codespaces für Entwicklung und Tests innerhalb der Kontingente. Dauerhosting, Keepalive-Tricks, Mining und Quotenumgehung sind ausgeschlossen.
